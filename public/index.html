Getting started

                
ReStreamAir re-streams DASH/HLS sources as clean HLS you can play in any player. Create a Provider (a group of streams that share settings/credentials), add Streams under it, then hit play or copy the output URL.

                
    
                  
  1. Go to Providers → New provider.
    2. 
                  
  2. Open the provider, add a stream with its source URL (an .mpd or .m3u8).
    3. 
                  
  3. Press Start, then Copy output URL and open it in VLC / a browser / an IPTV player.
    4. 
                

              


              

                
Providers & streams

                
Provider settings hold defaults shared by every stream under them: proxy, generic headers, and a provider script + accounts. A stream inherits these unless it overrides them.

                
    
                  
  • Proxy — set once on the provider; a stream's “Network override” wins if filled.
    • 
                  
  • Mixer settings (Playlist count, Keep count, Download ahead, Poll seconds) are per-stream, in the stream editor's DASH options.
    • 
                  
  • All Streams tab: bulk start/stop/delete, filter by provider/type, and Import channels/events from a provider script.
    • 
                

              


              

                
Playback & output

                
Every stream is served at /play/<id>/index.m3u8. The Input/output pipeline section chooses how it's produced:

                
    
                  
  • Internal remuxer (default) — no ffmpeg needed; downloads + remuxes segments itself, decrypting CENC clear keys.
    • 
                  
  • FFmpeg modes — spawn a resident ffmpeg that reads the source and copy-remuxes to HLS, or pushes to SRT/UDP/TCP via the Output target.
    • 
                  
  • Direct source — /play 302-redirects to the origin instead of proxying.
    • 
                

              


              

                
Provider scripts & Protocol

                
A script is any .py / .sh / executable that owns login, session management, or DRM/key logic. It's invoked with flat key=value arguments and prints its output to stdout (logs/debug to stderr).

                
Common Input (always passed to every action):
action=<name> user=<user> password=<pass> bind=<bind> proxy=<proxy> doh=<doh> worker=<worker> plus per-stream Script params (e.g. id=123 streamId=456).


                

                  
ActionInputs passedExpected Output (stdout)

                  
login / pairCommon argsLive text progress to stderr/stdout; script caches session token to disk.

                  
channelsCommon argsJSON: {"Channels": [{"Name": "...", "Mode": "live", "SessionManifest": true, "UseCdm": true, "CdmType": "widevine", "ScriptParams": "id=101"}]}

                  
eventsCommon argsJSON: {"Events": [{"Name": "...", "Mode": "live", "SessionManifest": true, "Autostart": true, "Start": 1700000000, "End": 1700007200, "ScriptParams": "eventId=50"}]}

                  
epgCommon argsXMLTV XML data string or JSON: {"EPG": [{"ChannelId": "101", "Title": "Show", "Start": 1700000000, "End": 1700003600}]}

                  
manifestCommon args + Script paramsJSON: {"ManifestUrl": "https://...", "Cdn": [{"Name": "c1", "ManifestUrl": "..."}], "Headers": {"Manifest": {...}, "Media": {...}}, "Heartbeat": {"PeriodMs": 300000}}

                  
downloadmanifestCommon args + url=<url>Raw manifest text (MPD/M3U8) or JSON: {"ManifestContent": "..."}

                  
downloadmediaCommon args + url=<url>Raw binary segment payload streamed to stdout.

                  
psshCommon args + pssh=<pssh> url=<url>JSON: {"ProcessedPssh": "AAAA..."}

                  
cdmCommon args + cdm=external|internal cdmType=widevine|playready pssh=<pssh> kid=<kid>Clear keys: KID:KEY lines, --> KID:KEY lines, or JSON: {"keys": [{"kid": "...", "key": "..."}]}

                  
heartbeatCommon args + Script paramsPings server session. Exit code 0 = success, non-zero = failure. JSON output optional.

                  
initCommon args + Script paramsOne-time session setup when a stream starts (best-effort). Output logged. Optional.

                  
startCommon args + Script paramsFired when a stream goes live — e.g. claim a concurrent-stream slot (best-effort). Optional.

                  
stopCommon args + Script paramsFired when a stream stops — end the session / release a slot (best-effort). Optional.

                

                
Lifecycle hooks (init/start/stop/heartbeat) only fire for script-driven streams (session manifest, CDM keys, heartbeat, or script params set), and never block the panel — a script that doesn't implement one just logs a benign line.

                
Import JSON per item uses keys: Name, Mode (live/vod), SessionManifest, UseCdm, CdmType, CdmMode, Video, Autostart, Start/End, and per-stream params.

              


              

                
DRM / keys

                
ReStreamAir is an IPTV restreamer, not a DRM client — it never runs a real Widevine/PlayReady/FairPlay CDM. For protected streams a script returns clear keys and the remuxer decrypts with them.

                
    
                  
  • Manual keys — paste KID:KEY hex pairs (one per line) in the stream editor's decryption box. These always win.
    • 
                  
  • Get keys via script — turn on in Scripting & DRM; the cdm action returns keys when the stream is protected and no keys were pasted.
    • 
                  
  • CDM mode — external: the script runs its own CDM and prints KID:KEY. internal: the panel scrapes kid=/pssh= from the manifest and the script proxies the license.
    • 
                

                
Key output formats accepted: bare KID:KEY lines, --> KID:KEY, or JSON {"keys":[{"kid","key"}]}.

              


              

                
Session manifest & heartbeat

                
When a source URL is short-lived (per-session/token), turn on Session manifest. On every start the panel runs the script's manifest action and streams from the fresh URL it returns:

                
{
  "ManifestUrl": "https://…/live.mpd",
  "Cdn": [ { "Name": "cdn2", "ManifestUrl": "https://…" } ],
  "Headers": { "Manifest": { "User-Agent": "…" }, "Media": { … } },
  "Heartbeat": { "Url": "", "Params": "", "PeriodMs": 300000 }
}

                
CDN mirrors become failover sources, Headers apply per fetch category, and Heartbeat.PeriodMs auto-sets the heartbeat interval (which re-runs the heartbeat action that often to keep the session alive).

              


              

                
Running the binary

                
On Linux, download the …-linux-x86_64.tar.gz release, extract, and run the launcher — not the raw binary:

                
tar -xzf restreamair-vX-linux-x86_64.tar.gz
cd restreamair-vX-linux-x86_64
./restreamair --port 8787 --bind 0.0.0.0

                
restreamair is a wrapper that points LD_LIBRARY_PATH at the bundled libs/ (so it works on distros that ship a different libxml2 soname). To update, replace the folder (or drop the new restreamair-linux over the old one).

              


              

                
API keys & CLI

                
    
                  
  • API Keys tab — generate keys to require auth on playback; add ?key=… to the play URL.
    • 
                  
  • Export playlist — one M3U of every stream, for VLC/Kodi/an IPTV app.
    • 
                  
  • CLI: restreamair cdmprobe mpd=<url> [script=<path>] prints the DRM challenge (KIDs/PSSH) and, with a script, the clear keys — handy for testing a CDM script.
